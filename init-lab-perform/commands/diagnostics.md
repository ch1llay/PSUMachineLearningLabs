# /diagnostics — Диагностика готовности репозитория

Проведи полную диагностику текущего репозитория для автономного выполнения лабораторных работ.

$ARGUMENTS

## Инструкция

1. Прочитай файл `.claude/DIAGNOSTICS_PROMPT.md` в текущем репозитории
2. Если файл не найден — сообщи пользователю:
   - "Файл `.claude/DIAGNOSTICS_PROMPT.md` не найден. Инициализируйте репозиторий через `/init-lab-repo`."
   - Завершись.
3. Если файл найден — выполни ВСЕ проверки из него последовательно
4. Каждую bash-команду из промта выполняй через Bash tool
5. Собери результаты и выведи итоговую сводку:
   - Количество OK / ПРОБЛЕМА
   - Список всех проблем с командами для исправления
   - Вердикт: ГОТОВО К ЗАПУСКУ / НУЖНО ИСПРАВИТЬ
6. Если пользователь передал аргументы ($ARGUMENTS типа "fix") — автоматически исправь найденные проблемы где это безопасно (chmod, создание директорий, но НЕ установка пакетов)
