### Шаг 5 — Реализуй

**Работа через MCP Jupyter (предпочтительный способ):**

1. Подключись к серверу:
   `mcp__jupyter__connect_to_jupyter` (url: `http://localhost:8888`, token: `psu-ml-token`)

2. Создай или открой ноутбук:
   `mcp__jupyter__use_notebook` (notebook_path: `lab{N}/lab{N}.ipynb`)
   Если ноутбук не существует — он будет создан автоматически.

3. Добавляй ячейки по одной и сразу выполняй:
   - Для markdown: `mcp__jupyter__insert_cell` (cell_type: `markdown`, source: `# Заголовок...`)
   - Для кода: `mcp__jupyter__insert_cell` (cell_type: `code`, source: `import pandas as pd...`)
   - Выполнение: `mcp__jupyter__execute_cell` (cell_id: `...`)

4. Если ячейка упала — исправь через:
   `mcp__jupyter__overwrite_cell_source` (cell_id: `...`, source: `исправленный код`)
   Затем снова `execute_cell`.

5. После завершения работы:
   `mcp__jupyter__unuse_notebook`

**Fallback через nbconvert (если MCP Jupyter недоступен):**

```bash
source /home/ilya/venvs/psu-ml/bin/activate && jupyter nbconvert --to notebook --execute lab{N}/lab{N}.ipynb --output lab{N}.ipynb --ExecutePreprocessor.timeout=300
```

**Обязательная структура ноутбука:**

1. Заголовок: "Лабораторная работа {N} — {тема}"
2. Цель работы (1-2 предложения)
3. **Теоретическое введение** (3-5 абзацев на русском, формулы если уместно)
4. Загрузка и описание данных
5. Основная часть — перед КАЖДЫМ блоком кода markdown-ячейка: зачем это делаем и какой принцип за этим стоит
6. Визуализации с подписями осей, заголовками и интерпретацией результатов
7. **Выводы**: что узнали, какие результаты получили, практическое значение

**Стратегия обработки ошибок:**

- Максимум 5 попыток исправления на одну ячейку
- При каждой ошибке: прочитай traceback → найди причину → исправь → повторно выполни
- После 5 неудач: закомментируй проблемный код, добавь markdown "Известная проблема: [описание]", двигайся дальше
- Если nbconvert падает 3 раза подряд: сохрани ноутбук как есть, пометь коммит "partial execution"
- Используй context7 MCP для проверки документации при ошибках API библиотек
