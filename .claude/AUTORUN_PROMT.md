## Процесс для КАЖДОЙ лабы N

**Шаг 1 — Изучи задание**
Прочитай задание из папки `машинное обучение/машинное обучение/` (папка соответствующего раздела по CLAUDE.md).

**Шаг 2 — Изучи примеры**
- `examples/Лабы Примеры Федя/ML_Lab{N}_Ulchenko_24VVIm1.ipynb`
- `examples/лабы примеры Олег/Машинное обучение/LW{N}/LW{N}.ipynb`
Запиши: что они сделали, что можно улучшить.

**Шаг 3 — Составь план**
Создай `lab{N}/PLAN.md` с детальным планом: секции ноутбука, методы, визуализации.
Цель — сделать ЛУЧШЕ чем у одногруппников.

**Шаг 4 — Проверь план**
Убедись что все требования из задания покрыты. Если нет — дополни PLAN.md.

**Шаг 5 — Реализуй**
Создай `lab{N}/lab{N}.ipynb`:
- Все markdown ячейки на русском языке
- Датасет: `datasets/gtzan/features_30_sec.csv`
- После написания запусти:
```bash
source .venv/bin/activate && jupyter nbconvert --to notebook --execute lab{N}/lab{N}.ipynb --output lab{N}/lab{N}.ipynb --ExecutePreprocessor.timeout=300
```
- Если ошибки — исправь и перезапусти. Не двигайся дальше пока ноутбук не выполняется без ошибок.

**Шаг 6 — Коммит**
```bash
git add lab{N}/
git commit -m "feat: лаба {N} — {тема}

- Реализовано: [список]
- Датасет: GTZAN Genre Collection
- Методы: [список]"
```

**Шаг 7 — Обнови README.md**
В таблице замени статус лабы {N} с `—` на `done`.
```bash
git add README.md && git commit -m "docs: обновлён статус лабы {N} в README"
```

**Шаг 8 — Сигнализируй завершение лабы**
```bash
python3 -c "
import json
d = json.load(open('.claude/progress.json'))
d['status'] = 'lab_done'
json.dump(d, open('.claude/progress.json', 'w'), indent=2)
"
```

## Правила
- НЕ останавливайся после завершения лабы — хук сам выдаст команду на следующую
- Если файл примера не найден — продолжай только по заданию
- После лабы 16 установи `current_lab: 17` в progress.json — это сигнал полного завершения
