# План: интерактивный учебник для быстрой подготовки к экзамену по МО

> Цель — пройти материал **быстрее, чем чтением**, и **понять суть** (формулы преподаватель разрешил распечатать).
> Принцип — read-see-quiz-next: коротко прочитал → увидел картинку/интерактив → ответил 3–5 вопросов → дальше.

---

## 1. Что мы знаем о материале

- 41 вопрос в 6 блоках:
  - **A. Введение** — 2 вопроса
  - **B. Подготовка данных** — 9 вопросов
  - **C. Регрессия** — 5 вопросов
  - **D. Классификация и кластеризация** — 12 вопросов
  - **E. Ансамбли** — 4 вопроса
  - **F. Нейронные сети** — 9 вопросов
- ~2400 строк связного текста + отдельная шпора с формулами.
- Преподаватель проверяет **понимание**, не зубрёжку формул.
- Каждый ответ уже структурирован: «суть в одном предложении → ядро → интуиция → подводные камни» — почти готовый каркас для карточки.

---

## 2. Формат — что собираем

**Один HTML-файл**, открываемый офлайн в браузере. Никаких сборок, никаких серверов. Прогресс — в `localStorage`.

Стек:
- Tailwind через CDN — стили без боли.
- **KaTeX** — рендер формул из ANSWERS.md и FORMULAS.md.
- **Mermaid** — блок-схемы (pipeline, дерево решений, иерархия ИИ).
- **Chart.js** — графики и интерактивные демо.
- Vanilla JS — навигация, квизы, прогресс.

Почему не React-артефакт: один файл удобнее для оффлайн-чтения с телефона/планшета и легко перенести в любую папку.

Фишки:
- **Хоткеи**: ←/→ — переход между темами, `1–5` — ответ на вопрос теста, `J/K` — листать сайдбар, `⌘K` — быстрый поиск.
- **Закладки** — «отметить, вернуться позже» (отдельная кнопка ⭐ на карточке).
- **Финальный режим «только тесты»** — прогнать квизы подряд по слабым темам (где % правильных < 80).
- **Мобильная версия** — сайдбар в `<details>`-меню сверху.

## 4. Шаблон карточки темы (одинаковый для всех 41)

1. **💡 TL;DR** — 1–2 предложения, можно закрыть глаза и пересказать.
2. **🧠 Интуиция** — метафора или mental model. Главный «крючок», за который зацепится память.
3. **📊 Визуализация** — одна картинка/диаграмма/интерактив. Если её сложно сделать — статичная схема через Mermaid.
4. **📐 Ключевые формулы** — 2–4 шт., каждая с пояснением «что говорит» (не для заучивания).
5. **⚠️ Подводные камни** — 3–5 пунктов, частые ошибки.
6. **🎯 Тест** — 3–5 вопросов с моментальным фидбеком и объяснением.
7. **Кнопка → следующая тема**.

Лимит: одна карточка читается **3–5 минут**.

## 5. Карта визуализаций (что и где показываем)

Самое важное — без хороших картинок учебник станет обычным текстом. Список — что планирую сделать для каждой темы.

### Блок A
- **Q1.** Вложенные круги Эйлера: AI ⊃ ML ⊃ ANN ⊃ DL + примеры задач рядом.
- **Q2.** Кривые train/val loss — overfitting vs underfitting; bias-variance как мишень со стрелами.

### Блок B
- **Q3.** Mermaid-схема pipeline: raw → impute → encode → scale → select → model.
- **Q4.** Сравнение «до/после» mean/median/KNN-импьютера на одной выборке.
- **Q5.** Boxplot с подсветкой IQR, ползунок «процент выбросов».
- **Q6.** Интерактив: вводим категорию → видим OneHot / Ordinal / Target вектора.
- **Q7.** Scatter «до/после» — Standard vs MinMax vs Robust на данных с выбросом.
- **Q8.** Сравнительная таблица filter/wrapper/embedded + анимация RFE.
- **Q9.** Heatmap корреляций; ползунок порога — какие признаки удалить.
- **Q10.** PCA-демо: облако точек 2D → главные оси → проекция; scree plot рядом.
- **Q11.** SMOTE до/после на двумерном дисбалансе классов.

### Блок C
- **Q12.** Анимация подбора линии МНК: как сумма квадратов уменьшается с шагами.
- **Q13.** Predicted vs actual + цветные R², MAE на одной диаграмме.
- **Q14.** «Путь коэффициентов» Lasso/Ridge при росте λ; геометрия L1 (ромб) vs L2 (круг).
- **Q15.** Сигмоида + граница решения 2D (ползунок threshold).
- **Q16.** Полиномиальная регрессия: degree 1 → 3 → 9 (видно переобучение).

### Блок D
- **Q17.** Дерево вероятностей с числами для классической задачи (медицинский тест).
- **Q18.** Пошаговый расчёт NB на крошечном примере.
- **Q19.** Интерактив kNN: ползунок k → меняется граница решения.
- **Q20.** Картинка готового дерева + структурные термины.
- **Q21.** Анимация выбора признака по IG/Gini шаг за шагом.
- **Q22.** Ползунок max_depth → видно, как граница из «лоскутной» становится гладкой.
- **Q23.** SVM-демо: точки, гиперплоскость, опорные вектора; мягкий зазор через C.
- **Q24.** Сравнение Эвклид/Манхэттен/Чебышёв/Косинус — единичные шары.
- **Q25.** K-means: 5 шагов анимации (init → assign → update → … → convergence).
- **Q26.** Дендрограмма + DBSCAN на «двух полумесяцах» (где K-means проваливается).
- **Q27.** Схема k-fold и Stratified k-fold; nested CV — две вложенные петли.
- **Q28.** Интерактивная матрица ошибок + ROC/PR-кривые с движущимся threshold.

### Блок E
- **Q29.** Hard vs Soft voting на простом примере.
- **Q30.** Бутстрэп: 0.632 — анимация выбора объектов с возвращением.
- **Q31.** AdaBoost: 3 итерации — видно, как ошибочные точки «толстеют».
- **Q32.** GBM: пошаговое подгоны псевдоостатков (residuals).

### Блок F
- **Q33.** Нейрон: ползунки w₁, w₂, b → меняется выход.
- **Q34.** Графики всех активаций на одной канве (sigmoid, tanh, ReLU, Leaky ReLU, ELU, GELU) + их производные.
- **Q35.** Распределения весов при LeCun / Xavier / He.
- **Q36.** MLP с 2 скрытыми слоями — клик по нейрону подсвечивает входы/выходы.
- **Q37.** Анимация прямого/обратного прохода — какие δ едут назад.
- **Q38.** Размерности тензоров: картинка → (H, W, C) → батч (B, C, H, W).
- **Q39.** Вычислительный граф f(x) = sin(x²) — forward + backward значения.
- **Q40.** Ландшафт loss с отметкой минимума, плато, седла.
- **Q41.** Сравнительные траектории SGD / Momentum / RMSProp / Adam на функции Розенброка.

Не везде нужен сложный интерактив — где работает простая статичная схема, делаем её. Цель — **наглядность, не Pixar**.

## 6. Философия квизов

Не «напиши формулу backprop», а проверка понимания:

- *«Признак — зарплата с выбросами справа. Какой scaler?»* → Robust, потому что …
- *«Accuracy = 99%, recall = 0%. Что произошло?»* → дисбаланс классов, модель предсказывает мажоритарный.
- *«L1 vs L2: какой даёт разреженность и почему?»* → L1, угол ромба попадает на оси.
- *«Увеличили max_depth дерева — что с bias и variance?»* → bias↓, variance↑.
- *«В Adam β₁ управляет … β₂ управляет …»* → momentum / RMSProp-часть.

Формат:
- 3–5 вопросов на тему.
- Multiple choice (4 варианта) — 80%; «вписать число/слово» — 20%.
- После ответа — мгновенный фидбек: ✅/❌ + 1–2 строки объяснения.
- В конце темы — мини-результат (3/5) и кнопка «повторить тест».

В сайдбаре у каждой темы появляется индикатор: 🟢 ≥ 80%, 🟡 50–80%, 🔴 < 50%. Видно слабые места.

## 9. Альтернативы (что отбрасываем и почему)

- **Минимум**: один большой Markdown с улучшенной вёрсткой. Быстро, но не интерактивно — теряем главное преимущество перед просто чтением ANSWERS.md.
- **PDF**: статичный, без квизов и интерактива. Хуже HTML по всем параметрам.
- **React-артефакт в чате**: ограничен размером, нет offline-доступа, плохо работает с математикой и Mermaid одновременно.
- **PowerPoint с тестами**: возможно, но это часы вёрстки, а интерактива минимум.

→ **Оптимум**: один HTML-файл.

## 10. Что подтвердить перед стартом

1. **Формат**: один HTML-файл — ок? (или хочешь .jsx-артефакт прямо в чате?)
2. **Когда экзамен** — горит сегодня/завтра или есть несколько дней? От этого зависит, можно ли делать поэтапно или нужно урезать визуализации ради скорости.
3. **Темы, которые ты уже знаешь** — можно пропустить или оставить только тест без чтения. Например, если уверен в Блоке A — там только 2 вопроса, проскакиваем.
4. **Глубина визуализаций**: «строгий минимум — Mermaid + статика» (быстрее) vs «много интерактивов с ползунками» (нагляднее, но дольше)?
5. **Доставка**: получать после каждого блока (можно начать читать раньше) или дождаться всё целиком?

После твоих ответов сразу начинаю Этап 1 (каркас + блок A).
