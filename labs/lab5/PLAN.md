# План: Лабораторная работа 5 — Очистка данных

## 1. Требования (из задания)

1. Загрузить выборку с Kaggle (используем GTZAN)
2. Проанализировать данные на наличие пропущенных значений
3. Заполнить пропущенные значения
4. Выявить и удалить выбросы

## 2. Чек-лист покрытия

| # | Требование | Реализация |
|---|-----------|------------|
| 1 | Загрузка данных | pd.read_csv GTZAN + info(), describe() |
| 2 | Анализ пропусков | isnull().sum(), визуализация пропусков (heatmap), процент пропусков |
| 3 | Заполнение пропусков | Искусственное внесение + SimpleImputer (mean, median), IterativeImputer, сравнение |
| 4 | Выявление выбросов | IQR-метод, boxplot до/после, Z-score, подсчёт выбросов |
| 5 | Удаление выбросов | Фильтрация по IQR, Winsorization, сравнение размера до/после |
| 6 | Дубликаты | Проверка и удаление дубликатов |
| 7 | Неинформативные признаки | Поиск признаков с >95% одинаковых значений |

## 3. Структура ноутбука

1. Заголовок и цель работы
2. Теоретическое введение (типы пропусков, методы заполнения, выбросы)
3. Загрузка и первичный осмотр данных
4. Анализ пропущенных значений (+ искусственное внесение, т.к. GTZAN чистый)
5. Заполнение пропусков: SimpleImputer, IterativeImputer, сравнение стратегий
6. Анализ дубликатов и неинформативных признаков
7. Выявление выбросов: IQR-метод, Z-score, boxplot
8. Удаление/обработка выбросов: фильтрация, Winsorization, сравнение
9. Итоговая статистика (до/после очистки)
10. Выводы

## 4. Теоретические темы

- Типы пропусков: MCAR, MAR, MNAR
- Методы заполнения: удаление, среднее/медиана, SimpleImputer, IterativeImputer
- Выбросы: определение, IQR-метод, Z-score
- Winsorization — замена выбросов граничными значениями
- Дубликаты и неинформативные признаки

## 5. Визуализации (минимум 3)

1. Heatmap пропущенных значений (msno/seaborn)
2. Сравнение распределений до/после заполнения пропусков
3. Boxplot до/после удаления выбросов
4. Гистограмма количества выбросов по признакам
5. Scatter plot: сравнение оригинальных и заполненных значений
