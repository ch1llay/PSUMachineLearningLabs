# План: Лабораторная работа 1 — Загрузка табличных данных

## 1. Требования (из задания)

1. Загрузить датасет
2. Вывести первый и третий столбцы по отдельности и вместе
3. Вывести первые 10 строк и 23 случайных строки
4. Вывести статистику по числовым показателям
5. Сгруппировать данные по столбцу (label)
6. Фильтрация по условию

## 2. Структура ноутбука

1. Заголовок + цель работы
2. Теоретическое введение: pandas, DataFrame, Series, основные операции
3. Загрузка GTZAN
4. Обзор данных: shape, info, dtypes
5. Выборка столбцов (по отдельности и вместе)
6. Выборка строк: head, sample
7. Фильтрация по условию
8. Описательная статистика (describe)
9. Группировка по жанру
10. Визуализации
11. Выводы
