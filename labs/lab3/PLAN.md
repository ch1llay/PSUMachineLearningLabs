# План: Лабораторная работа 3 — Описательная статистика

## 1. Требования

1. Загрузить датасет
2. Вычислить метрики описательной статистики (среднее, медиана, мода, дисперсия, std, квантили)
3. Построить графики распределений
4. Проанализировать корреляции

## 2. Структура ноутбука

1. Загрузка GTZAN
2. Описательная статистика: describe, mean, median, mode, var, std
3. Квантили и IQR
4. Распределения (histograms, KDE)
5. Boxplots
6. Корреляционная матрица (heatmap)
7. Pairplot
8. Выводы
