# План: Лабораторная работа 6 — Отбор признаков

## 1. Требования (из задания)

1. Загрузить выборку с Kaggle (используем GTZAN)
2. Проанализировать датасет
3. Выполнить отбор признаков двумя различными методами из изученных категорий

## 2. Чек-лист покрытия

| # | Требование | Реализация |
|---|-----------|------------|
| 1 | Загрузка данных | pd.read_csv GTZAN + подготовка (LabelEncoder для label) |
| 2 | Анализ датасета | describe(), корреляционный анализ, дисперсия |
| 3 | Фильтрующие методы | Mutual Information, Chi-squared (SelectKBest) |
| 4 | Обёрточные методы | RFE (Recursive Feature Elimination) |
| 5 | Встроенные методы | LASSO (L1), Random Forest feature importance |
| 6 | Сравнение методов | Консенсус + оценка качества классификации |

## 3. Структура ноутбука

1. Заголовок и цель работы
2. Теоретическое введение (фильтры, обёртки, встроенные методы)
3. Загрузка и подготовка данных
4. Фильтрующие методы: Mutual Information + Chi-squared
5. Обёрточный метод: RFE с LogisticRegression
6. Встроенные методы: LASSO + RF feature importance
7. Консенсусный отбор — пересечение методов
8. Оценка классификации: все признаки vs отобранные
9. Выводы

## 4. Теоретические темы

- Проклятие размерности
- Фильтры, обёртки, встроенные методы
- Mutual Information, Chi-squared

- Feature importance из ансамблей

1. Barplot — Mutual Information scores
