# План: Лабораторная работа 7 — Кодирование и масштабирование

## 1. Требования

1. Загрузить выборку с Kaggle (GTZAN)
2. Проанализировать данные на наличие категориальных и числовых признаков
3. Обработать категориальные признаки (кодирование)
4. Привести числовые признаки к единому масштабу

## 2. Чек-лист покрытия

| # | Требование | Реализация |
|---|-----------|------------|
| 1 | Загрузка | pd.read_csv, определение типов |
| 2 | Кодирование | LabelEncoder, OrdinalEncoder, OneHotEncoder для label |
| 3 | StandardScaler | Z-нормализация |
| 4 | MinMaxScaler | [0,1] масштабирование |
| 5 | MaxAbsScaler | [-1,1] масштабирование |
| 6 | Normalization | L2-нормализация |
| 7 | Pipeline | ColumnTransformer для автоматизации |
| 8 | Сравнение | Визуализация распределений до/после |

## 3. Визуализации (минимум 3)

1. Гистограммы до/после StandardScaler
2. Boxplot сравнение всех скейлеров
3. Heatmap корреляций после масштабирования
4. Bar chart — влияние масштабирования на accuracy

## 4. Наши преимущества

- ColumnTransformer + Pipeline (ни Федя, ни Олег не используют)
- Сравнение влияния скейлеров на accuracy классификатора
- Визуальное сравнение распределений всех скейлеров
